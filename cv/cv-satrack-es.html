PROYECTOS TÉCNICOS DESTACADOS

UrbaniaSoft — Plataforma multi-tenant de administración de propiedades

Proyecto de backend y arquitectura construido con ASP.NET Core 9, PostgreSQL y Entity Framework Core. Solución basada en Clean Architecture y DDD con CQRS, autorización por roles y membresías, autenticación JWT, SignalR, FluentValidation y multi-tenancy con aislamiento garantizado en la capa de persistencia. Incluye una arquitectura desacoplada de almacenamiento de archivos integrada con Cloudflare R2 y configuración para despliegue en la nube.

Stack: ASP.NET Core 9 · C# · EF Core · PostgreSQL · JWT · SignalR · FluentValidation · Cloudflare R2 · Render — urbani-soft.vercel.app

EvolvePOS — Sistema de punto de venta offline-first

Diseño y desarrollo de la arquitectura backend de un POS con persistencia local en SQLite y sincronización contra una API remota. Aplica Clean Architecture, DDD, CQRS y el patrón Outbox para garantizar que ninguna transacción se pierda ni se duplique cuando la conectividad falla. Implementa los flujos de cierre de venta y pago en efectivo con separación estricta entre dominio, aplicación e infraestructura.

Stack: .NET 8 · C# · SQLite · Clean Architecture · CQRS · DDD · Outbox Pattern · Offline-First

SoundIA — Plataforma musical con integración de IA

Plataforma full-stack con backend en ASP.NET Core 9 y frontend en React/Vite/Tailwind. Integra APIs externas mediante un motor de proveedores de letras con validación semántica, además de persistencia en SQLite, migraciones automáticas, health checks y Swagger en desarrollo. Backend contenerizado con Docker y desplegado en la nube.

Stack: ASP.NET Core 9 · React · Vite · Tailwind CSS · SQLite · Docker · APIs externas · IA — sound-ia.vercel.app

ControlInventory — Aplicación móvil de gestión de inventario

Aplicación Android de inventario con arquitectura por capas, MVVM, inyección de dependencias y UI declarativa, estructurada alrededor de la mantenibilidad y la separación de responsabilidades para flujos reales de inventario.

Stack: Kotlin · Jetpack Compose · MVVM · Hilt · Clean Architecture

EneModa — Aplicación web de comercio electrónico

Interfaz de comercio electrónico responsive construida con React y Tailwind CSS sobre un sistema de componentes reutilizables, con foco en la experiencia de usuario. Desplegada en Vercel.

Stack: React · Tailwind CSS · Vercel — ene-moda.vercel.app
